# Team Robo Release Documentation Site

Documentation for Team Robo's open-source RoboCup@Home software stack.

## Local development

Set up the environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Serve locally:

```bash
zensical serve
```

or:

```bash
mkdocs serve
```
